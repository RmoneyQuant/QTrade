What that graph actually means

scheduler is built, not load-bearing

Priority queue + SimClock, tie-break logic, its own tests pass (T04). Grepping every file in the tree for crate::scheduler turns up zero real callers. Not broken — just not plugged into anything yet.

mcx-decoder is narrower than it looks

main.rs declares all eight phase-1 modules with #[allow(dead_code)] so the whole core compiles as part of it — but its main() makes exactly one call: decoder::decode_file. The rest just ride along.

backtester is the only full path — and only backtest

It's the sole binary that wires book, cache, simulator, execution, feed_replay, and a strategy together end to end. No live feed source exists anywhere in this codebase; passing mode=live fails cleanly rather than pretending to work.
